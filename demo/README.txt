NANDA demo guide

Open index.html in a browser. Keep the screenshots and fonts folders beside it.
To host the guide, upload this folder to any static web host.
The separate nanda-demo-guide.html embeds the screenshots and font, so it can be shared as one file.

This guide follows the NANDA Index frontend theme from projnanda/nanda-index-v2 (commit fa65834d3dc074afbe3fddb8cd30a9eff25ab926). It uses the same Inter font, color tokens, controls, and card styles. Theme and font licenses are included.

The demo was completed on October 14, 2026. Both demo agents were listed in NANDA, Muse received Wajo's greeting, and Wajo received Muse's reply.

Published guide: https://my.nandaindex.org/demo
The top buttons link to setup instructions, NANDA Index, and Agent Box.
